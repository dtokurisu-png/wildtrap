1. Esculpir el terreno

✂ Perforar la malla (cuevas y arcos)

Marca el área con el pincel amarillo. Pulsa Crear agujero para eliminar las caras reales del terreno, o Restaurar terreno para cerrarlas. No borra las alturas: puedes deshacer o restaurar después.

0 celdas seleccionadas · 0 celdas perforadas

El radio se ajusta arriba con Radio del pincel. El agujero deja espacio para colocar después un modelo 3D independiente de cueva, túnel o arco.

2. Importar mapa de alturas

Una imagen limpia con tonalidades verdes. Verde oscuro = zona alta; verde claro = zona baja. El editor convierte los tonos de luminosidad en una malla con relieve.

3. Anclajes, caminos y estructuras

Camino, muro, escalera y compuerta: haz clic en el punto inicial y luego en el final. Si colocas un anclaje cerca, el extremo se ajusta automáticamente a él. Las escaleras generan peldaños reales. La montaña es un módulo autónomo con camino espiral y entrada de cueva. El punto de spawn de árboles es solo un marcador: no genera árboles definitivos.

Estructuras / Cuevas · Fase 1

Seis modelos 3D independientes con mallas subdivididas, UV, normales e interiores reales. Selecciona una pieza, pulsa Colocar pieza y haz clic en el escenario. Puedes moverla con Mover y seleccionarla para cambiar sus dimensiones.

Selecciona una pieza para modificarla

En esta fase puedes colocar, seleccionar, mover, rotar, escalar y dimensionar. Las mallas ya admiten deformaciones por vértice en su formato interno. El pincel de esculpido sobre ellas y la exportación GLB se incorporarán en las fases 2 y 3.

4. Cueva bajo el terreno

Cada cueva tiene una entrada visible y una sala separada bajo la malla (Y = −15). Selecciona una cueva y pulsa «Entrar» para inspeccionarla en 3D. En el juego, el portal debe cambiar de capa de colisiones y activar solo los colliders del interior; no se desactivará todo el suelo.
